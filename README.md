## ✨ Особенности

- 🎨 **Уникальный дизайн**: современный интерфейс с плавными анимациями.
- ⚡ **Высокая производительность**: быстрая загрузка и оптимизированная работа.
- 🛡️ **Безопасность**: автоматическая проверка целостности файлов.
- 🧩 **Гибкость**: поддержка множества сборок и версий Minecraft.
- ☕ **Встроенная Java**: автоматический подбор и установка нужной версии Java.

## 📥 Установка

1.  Скачайте последнюю версию лаунчера со страницы [Releases](https://github.com/chebukak/CoreMC/releases).
2.  Распакуйте архив в удобное для вас место.
3.  Запустите `CoreMC-setup.exe`.

> [!WARNING]
> **Внимание!**
> Данная версия является **Pre-Release (v1.0.0)**. Возможны баги и нестабильная работа. Пожалуйста, сообщайте обо всех найденных проблемах в наш чат.
